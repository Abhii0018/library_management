# Shared UI Components

Framework: Django templates with semantic HTML and vanilla CSS/JavaScript.

## Button

- Source: `static/css/styles.css`
- Description: `.btn` base class with primary, secondary, status, and small variants.

```html
<a class="btn btn-primary" href="#">Action</a>
```

## Card

- Source: `static/css/styles.css`
- Description: `.card` surface used throughout authenticated pages.

```html
<section class="card">
  <div class="card-header"><div class="card-title">Title</div></div>
  <div class="card-body">Content</div>
</section>
```
