# LibriCore Design System

LibriCore is a scholarly digital athenaeum: deep navy surfaces, warm gold accents, crisp white cards, and Plus Jakarta Sans typography. Motion should feel calm and purposeful rather than flashy. Use real library imagery where available, preserve the existing shield logo, and keep all interactions usable on small screens.

## Interaction

- Use hover lift, soft glow, and staggered entrance for discovery surfaces.
- Use count-up for numeric metrics only when the element is visible.
- Respect `prefers-reduced-motion`.
